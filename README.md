# Southern Illinois Recruiting Site — V4

This build uses the V1 scrolling presentation format and the original supplied images for:
- Scott Nagy practice
- #0 Championship Culture player photo
- Men's Basketball Facility collage
- Meet the Team photo

It also embeds the original All The Legacy video (with a web-compatible MP4 copy plus the original MOV fallback).

## GitHub Pages
Upload the complete contents of this folder to the root of the `coachblaylock-spec/SIU` repository.

Personalize the recruit name with the URL query parameter:
`https://coachblaylock-spec.github.io/SIU/?n=Amarion`

Change `Amarion` to any recruit name.
