# SIU Recruiting Site

GitHub Pages-ready recruiting presentation for Southern Illinois men's basketball.

## Publish
1. Create a GitHub repository named `siu` under `coachblaylock-spec`.
2. Upload everything in this folder to the root of the repository.
3. In GitHub: Settings > Pages > Build and deployment > Deploy from a branch.
4. Select `main` and `/ (root)` and save.
5. The site will publish at `https://coachblaylock-spec.github.io/siu/`.

## Personalize a recruit
Add `?n=Name` to the URL, for example:
`https://coachblaylock-spec.github.io/siu/?n=Amarion`

## Photo/video upgrades
The first version intentionally uses labeled photo slots. Replace those blocks with approved SIU images/video once selected.
